# Interview question bank

Use the multiple-choice question tool: up to four questions a round, recommended option first, "(Recommended)" on its label. Skip anything already settled in the conversation, a routine prompt or the budget log, and say what you assumed instead. Build options from real values (the last agreed budget, the ad sets you are about to create), never from placeholders.

## Budget gate (whenever no budget is agreed for the period)

1. **Daily budget for <campaign>, net of VAT**: same as the last agreed amount (Recommended, if there was one) / a step down / a step up / other. Show the weekly total in each option's description (daily x 7).
2. **Split between ad sets**: weighted to the biggest audience, for example two thirds families and one third grandparents (Recommended) / equal / all in one ad set / other.
3. **Until when**: the campaign's end date (Recommended) / end of this week / until I say / other.
4. **After that**: stop and ask me again (Recommended) / carry on at the same budget until I say / pause everything.

Record the answers in the budget log (Google Sheet "Meta ads budget log": date, brand, campaign, ad set split, £ a day net of VAT, from, until, agreed by, notes). The director's words win over anything in the log.

## Launch round

1. **Publish**: publish now and I tell Musa to check (Recommended when the director asked Claude to post) / stage as drafts for Musa to review and publish / publish some now, the rest later.
2. **Landing link**: the tested page (name it, and say which other links failed) (Recommended) / another link I will give you / no link (only for reach-only ads).
3. **Button**: the button that matches the page, for example Sign up for a sign-up form (Recommended) / Book now / Learn more.
4. **AI label**: leave it off; our videos are made with code, licensed music and the brand's own photos (Recommended) / switch it on. Ask again for any creative made with a generative AI tool, because the declaration is the advertiser's responsibility and cannot be changed later.

## Test round

1. **What to A/B test**: thumbnail and hook, one test each (Recommended) / thumbnail only / hook only / no test.
2. **Winner decided by**: cost per link click (Recommended for awareness video) / cost per ThruPlay / cost per lead (lead campaigns).

## Monitoring round (first launch of a campaign)

1. **Pausing**: pause clear losers, then tell me (Recommended) / ask me before pausing / never pause.
2. **Checks**: day 5 to 7 check plus an end review (Recommended for up to two months) / weekly (Recommended for longer) / only when I ask.
3. **Who hears about it**: just me (Recommended) / me and Musa.
4. **When the budget period ends**: ask me (Recommended) / let ad sets end / carry on.

## Delivery round (after a launch)

1. **How did it go**: all good / change something (say what) / Musa will check and report back.
